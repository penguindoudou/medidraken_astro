# Task 5: Sources Block in gsc:draft

**Status:** ⬜ Todo
**Effort:** Small (~1h)

## What

Add a "suggested sources" section to the article draft generated by `gsc:draft`. The draft already embeds real GSC data — it should also suggest which sources to draw from when writing the content.

## Why

A new article without references is thin content. Swedish health pages compete against 1177.se, Vårdguiden, and academic sources — pages with real citations and authoritative references. An empty template doesn't prompt the writer to include any of this.

The draft is meant to be completed by a human or AI writer in a separate session. If that session starts without a sources list, it'll produce generic TCM copy instead of substantive, credible content.

## What to build

**`plans/sources.json`** — a curated, reusable sources list categorized by topic:
- Swedish medical/health authorities (1177.se, Socialstyrelsen, Folkhälsomyndigheten)
- Academic TCM research (PubMed search templates)
- Local context sources (Nyköping, Södermanland — tourism board, local business registry)
- Internal Medidraken pages to link to (treatments, courses, contact)

**Modify `scripts/gsc/generate-article-draft.js`** — before writing the draft file, look up relevant sources from `plans/sources.json` based on the keyword/topic, and prepend a `<!-- SOURCES -->` block at the top of the draft with 3–5 relevant links.

## Context files to read before implementing

- `scripts/gsc/generate-article-draft.js` — modify the `buildDraft()` function
- `plans/artikel-plan.md` — may contain existing source references to reuse
